# Soul de Minas — Landing Page Black Friday

Landing page de captação + página de obrigado para a campanha Black Friday do clube Soul de Minas.

## Estrutura

```
index.html       → LP de captação (lp.souldeminas.com)
obrigado.html    → Página de obrigado
vercel.json      → Config de roteamento Vercel
```

## Deploy

Projeto hospedado na Vercel. Domínio customizado: `lp.souldeminas.com`
